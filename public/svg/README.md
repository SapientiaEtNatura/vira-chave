# Elementos SVG (`public/svg/`)

Coloque aqui os arquivos `.svg` que deseja usar no site.

- Como referenciar no código: `/svg/nome-do-arquivo.svg` (ex.: `<img src="/svg/ilustracao.svg" alt="..." />` ou `background-image: url('/svg/ilustracao.svg')`).
- No Next.js, tudo dentro de `public/` é servido diretamente a partir da raiz `/`.
